# Entregable — Semana 1

## 1. Ficha de Idea de Producto

* **Nombre tentativo de la app:** PhysioTrack / KineHub
* **Problema que resuelve:** La falta de adherencia de los pacientes a sus ejercicios de rehabilitación en casa debido a que olvidan cómo hacerlos correctamente o pierden las guías impresas en papel, lo que retrasa su recuperación y dificulta el seguimiento del terapeuta.
* **Usuario objetivo (perfil):** Terapeutas físicos y ocupacionales que necesitan prescribir rutinas, y pacientes en proceso de recuperación de lesiones ortopédicas o neurológicas.
* **Jobs-to-be-done:**
    1. Como terapeuta, quiero asignar rutinas de ejercicios personalizadas con videos o descripciones claras para que mi paciente realice su rehabilitación correctamente en casa de forma autónoma.
    2. Como paciente, quiero registrar diariamente la finalización de mis ejercicios y reportar mi nivel de dolor para que mi terapeuta pueda ajustar mi tratamiento en la próxima consulta.
* **Propuesta de valor en 1 oración:** "Optimizamos la recuperación física conectando a terapeutas y pacientes a través de un seguimiento digital de rutinas claro, accesible y medible."
* **Tipo de app:** Negocio / Nicho (Salud y Bienestar / Herramienta B2B2C).

## 2. Backlog Inicial

A continuación, se presentan las historias de usuario iniciales estructuradas bajo el formato estándar, priorizadas para un Producto Mínimo Viable (MVP).

| ID | Historia de Usuario (Formato: "Como [usuario], quiero [acción], para [beneficio]") | Prioridad |
| :--- | :--- | :--- |
| **US-01** | Como **terapeuta**, quiero **iniciar sesión en la plataforma** para acceder al listado de mis pacientes asignados. | **Alta** |
| **US-02** | Como **terapeuta**, quiero **crear un nuevo perfil de paciente** para registrar sus datos básicos e historial de tratamiento. | **Alta** |
| **US-03** | Como **terapeuta**, quiero **seleccionar ejercicios de un catálogo predeterminado** para armar una rutina semanal para un paciente. | **Alta** |
| **US-04** | Como **paciente**, quiero **ver la lista de ejercicios asignados para el día de hoy** para saber exactamente qué movimientos debo realizar. | **Alta** |
| **US-05** | Como **paciente**, quiero **marcar un ejercicio como "completado"** para que quede registrado en mi historial de progreso. | **Media** |
| **US-06** | Como **paciente**, quiero **seleccionar un nivel de dolor (del 1 al 10) al terminar la rutina** para notificar a mi terapeuta cómo me sentí. | **Media** |
| **US-07** | Como **terapeuta**, quiero **visualizar un gráfico con el porcentaje de cumplimiento del paciente** para evaluar su disciplina antes de la siguiente sesión presencial. | **Media** |
| **US-08** | Como **administrador**, quiero **agregar nuevos ejercicios con sus respectivas descripciones al catálogo general** para mantener la base de datos actualizada. | **Baja** |
